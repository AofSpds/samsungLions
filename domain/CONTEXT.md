# SamsungLions 도메인 맥락 — SL-CONTEXT v0.2

- 도메인 ID: `samsung_lions`
- 성격: 친구·가족과 AI가 함께 쓰는 **범용 협업 작업 공간**. 소프트웨어 개발 전용이 아님
- 최종 결정 주체: 사람(Owner/협업자). AI의 제안이나 추론은 결정이 아님
- 기본 역할: 총괄 `pln`, 연구 `rsch`, 범용 작업 `pmo` — 정본은 [ROLES.md](ROLES.md)
- 프로젝트 전체 목록: [PROJECTS.md](PROJECTS.md)
- 전체 현황: [STATUS.md](../STATUS.md)

## 최상위 영역

| 경로 | 정체 |
| --- | --- |
| `projects/` | 프로젝트 목표·상태·계획·요청·의사결정 |
| `works/` | 사진·동화·소설·음악·교육자료 등 초안 및 작품 |
| `apps/` | 실제 실행되는 앱·도구·자동화·AI 스킬 |
| `shared/` | 공통 템플릿·참고자료 |
| `domain/` | 모든 에이전트가 공유하는 도메인 맥락·역할·프로젝트 등록부 |

프로젝트와 작품/앱은 1:1이 아니다. 한 프로젝트가 여러 작업물을 만들거나 여러 프로젝트가 한 앱을 공유할 수 있다. 결과물 경로는 프로젝트 문서에 연결한다.

## 맥락의 3단계

1. **도메인(항상):** `AGENTS.md`, `domain/CONTEXT.md`, `domain/ROLES.md`, `domain/PROJECTS.md`, `STATUS.md`.
2. **프로젝트(배정되었을 때):** `projects/<name>/CURRENT.md`, `PLAN.md`, `DECISIONS.md`, 관련 `board/` 항목.
3. **세션(업무마다):** 선택된 역할, 선택된 프로젝트, 구체적인 요청, 작업 범위, 이전 결과. 자동으로 역할·프로젝트를 추측하지 않는다.

런타임의 컨텍스트 주입은 저장소 문서를 **읽어 전달**하는 것이지, 세션 기억이나 접근 권한을 만드는 것이 아니다. 누락·불일치·실행기 미지원은 `확인 안 됨`으로 표시한다.
