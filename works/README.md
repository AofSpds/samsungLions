# works — 작업물 보관소

소프트웨어 코드와 무관한 사진, 그림, 소설, 음악, 아이 교육자료 등 **초안부터 완성본까지 실제 작업물**을 저장합니다.

## 추천 분류

- `photos/` — 사진·이미지·삽화
- `stories/` — 소설·동화·기타 글
- `music/` — 음악·오디오 작업물
- `education/` — 학습지·수업자료·교구 콘텐츠
- `other/` — 아직 분류되지 않은 결과물

분류 폴더는 실제 콘텐츠가 생길 때 생성하며, 각 작품의 이름으로 하위 폴더를 나눌 수 있습니다. 가능한 경우 작품 설명, 제작 날짜, 버전, 사용한 출처·라이선스를 함께 기록합니다.

진행 과정과 일정은 `projects/`에서 관리하고, 프로젝트에서 이곳의 작업물 경로를 연결합니다.

> 이 저장소는 현재 **Public**입니다. 개인 사진이나 아이의 얼굴·이름·학교 등 비공개 정보가 포함된 자료는 올리지 마세요. 대용량 사진·음악 파일이 많아지면 Git LFS 또는 외부 저장소를 고려하세요.
