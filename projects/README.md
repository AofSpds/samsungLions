# projects — 프로젝트 작업 공간

각 프로젝트의 목표·진행 상태·작업 요청·결정을 관리하는 곳입니다. AAA의 **프로젝트 경계와 프로젝트 내 게시판·역할 공간**을 참고하되, 작은 협업에 맞춰 최소 구성부터 시작합니다.

## 새 프로젝트의 기본 형태

```text
projects/
└── <project-name>/
    ├── CURRENT.md       # 지금 상태, 담당, 다음 할 일
    ├── PLAN.md          # 목표·범위·완료 기준
    ├── DECISIONS.md     # 사람이 확정한 결정·근거
    ├── board/           # 실제 작업 건이 생기면 생성
    │   └── TASK-001.md
    └── roles/           # 역할 구분이 필요할 때만 생성 (선택)
```

`board/TASK-001.md`에는 최소한 **제목 / 요청자·담당 / 목표 / 상태(대기·진행·검토·완료) / 결과물 경로 / 남은 일**을 남깁니다. 단일 작업 건을 여러 단계 파일로 쪼갤 필요는 없습니다.

`roles/`는 여러 AI 또는 사람의 책임이 분리되어야 할 때만 열고, 필요하면 AAA처럼 기획(pln)·연구(rsch)·설계(arch)·구현(pmo) 등의 구분을 채택할 수 있습니다. **초기부터 전체 역할 구조를 만들 필요는 없습니다.**

실제 결과물은 `works/`, 실행 가능한 앱·도구·스킬은 `apps/`에 두고, 프로젝트 문서에서 상대 경로로 연결합니다.

현재 프로젝트는 아직 없습니다. 첫 프로젝트를 시작할 때 위 기본 문서를 만듭니다.
