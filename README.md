# SamsungLions Workspace

친구와 각자의 AI가 함께 프로젝트를 기획하고, 작업물을 만들고, 기록하는 공동 작업 공간입니다. 소프트웨어 개발만을 위한 저장소가 아닙니다.

## 작업 공간

| 경로 | 용도 |
| --- | --- |
| [projects/](projects/) | 프로젝트별 목표·진행 상태·작업 게시판·의사결정 관리 |
| [works/](works/) | 사진, 소설, 음악, 아이 교육자료 등 실제 작업물 보관 |
| [apps/](apps/) | 필요할 때 추가하는 앱·자동화 도구·AI 스킬 |
| [shared/](shared/) | 여러 프로젝트가 공유하는 참고자료와 템플릿 |

## 시작 방법

1. [AGENTS.md](AGENTS.md)의 공통 규칙을 읽습니다. Claude를 사용하는 경우 [CLAUDE.md](CLAUDE.md)도 참고합니다.
2. 새로운 일을 시작할 때는 `projects/<프로젝트명>/`에 목표와 현재 상태를 기록합니다.
3. 실제 창작물은 적절한 `works/` 하위 폴더에 두고, 프로젝트 문서에서 해당 경로를 연결합니다.
4. 앱이나 스킬이 생길 때만 `apps/` 하위 폴더를 만듭니다.
5. 여러 사람이 같은 파일을 작업한다면 별도 브랜치와 Pull Request로 변경을 합칩니다.

전체 개요는 [STATUS.md](STATUS.md)를 참조합니다. 프로젝트·작업물 하위 폴더는 실제 필요가 생길 때 생성합니다.

> **공개 저장소 주의:** 이 저장소는 현재 Public입니다. 개인 사진, 아이의 신상정보, 비공개 교육·생활자료, 계정·API 키 등 민감한 정보는 올리지 마세요. 비공개 협업이 목적이라면 저장소를 Private으로 전환한 뒤 사용하세요. 큰 사진·오디오 파일은 Git LFS 또는 외부 저장소 연계를 고려하세요.
